Project Description: 
This project is a full-stack contact form web application built using 
HTML, CSS, JavaScript, Node.js, Express, EJS, and MySQL. The application allows users to submit their contact information through a form,
and the data is stored securely in a database. It includes server-side validation, an admin login system to protect the admin page, 
and a dashboard where submitted entries can be viewed in a table. The site was also designed with responsive layout, accessibility 
considerations, and clean UI/UX practices to ensure it works well across different devices.
